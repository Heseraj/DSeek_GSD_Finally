<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SSE stream → browser | untrusted frames from the backend socket cross into client state and DOM |
| store → DOM | client state renders into the page (text-only rendering policy) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-02 | Tampering | usePriceStream onmessage / applyPrices | high | mitigate | JSON.parse inside try/catch (skip malformed frames); store type-guard rejects unknown tickers/shapes; the store never evaluates data (03-RESEARCH.md:534-535). Any non-conforming frame is dropped, not rendered. |
| T-03-04 | Tampering | store prices/portfolio state | low | accept | Client state is cosmetic — every mutation re-validates server-side; a forged store value can only change what the user sees, never executed trades (03-RESEARCH.md:537). |
| T-03-06 | Spoofing | connection indicator | low | accept | The dot reflects EventSource readyState truthfully; it is a status display, not a security boundary (03-RESEARCH.md:29). |
</threat_model>
