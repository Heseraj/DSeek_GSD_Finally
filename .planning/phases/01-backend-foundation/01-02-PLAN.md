## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→API | Untrusted JSON body {ticker, quantity, side} crosses into POST /api/portfolio/trade |
| API→SQLite | Trade execution writes cash, positions, trades, and snapshots transactionally |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | POST /api/portfolio/trade request body | medium | mitigate | Pydantic TradeRequest enforces quantity greater than 0 and side in Literal buy/sell; ticker is uppercase-stripped; unknown ticker or missing price returns 404; sufficient-cash (buy) and sufficient-shares (sell) checks return 400 |
| T-02-02 | Tampering | SQL writes during trade execution | medium | mitigate | Cash update, position upsert, trade insert, and snapshot run inside a single sqlite3 transaction using parameterized queries only |
| T-02-03 | Denial of Service | GET /api/portfolio/history unbounded row count | low | accept | Single-user local app; rows accrue at one per 30 seconds plus one per trade |
| T-02-SC | Tampering | npm/pip/cargo installs | low | accept | No new dependencies introduced; pydantic and sqlite3 already present |
</threat_model>
