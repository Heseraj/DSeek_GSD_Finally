| T-02-03 | DoS | litellm.acompletion | medium | mitigate | force_timeout=60 bounds each call; history cap (LIMIT 20) bounds prompt size; no retry loop on failure — a failed call returns the error ChatResponse immediately |
| T-02-04 | Tampering | ChatProposal parse of live output | medium | mitigate | model_validate_json inside the tolerant handler; schema-violating output returns an error ChatResponse and executes/persists nothing; supports_response_schema check falls back to json_object so the provider cannot silently ignore the schema |
